Charts and Figures

Show example

Use the Charts & Figures Converter to help format charts and figures from MS Word HTML <table> to proper HTML code. The tool might not convert charts and figures that do not follow the Word template guide.

Quick Guide

  • The chart number and title belongs in the <figcaption class="panel-heading"> element. Make sure you use the <br> after the chart number and that the chart title is wrapped in a <b>
  • The <img> element must have the img-responsive and full-width classes. Include the chart title in the alt property
  • Notes, Sources and the Text Version expand/collapse go in the <footer class="panel-footer"> element
  • Notes and Sources should be in a <p class="small"> element
  • Do not remove the column system around the <figure>. This column system ensures the table dosnt take up to much space on the page.

Text version expand/collapse

  • if in and English page, add the text "Text Version" in the <summary> element. If in a French page add the text "Version texte"
  • The expand/collapse needs to contain a text or table explaination of that chart/figure for accesibility reasons.
  • If using a table for the Text Version, it will be a very basic table and will only get the table class. Basic example below.

Example:


<details class="mrgn-tp-sm">
    <summary>Text version</summary>
    <div class="table-responsive">
        <table class="table">
        </table>
    </div>
</details>

Use the new Table Cleanup Tool to help convert your table from MS Word HTML to properly formatted HTML. The Table Cleanup Tool will restructure the table, remove unwanted properties, add proper classes and allows you to indicate which rows are Section Headings, Sub headings (indents) and column headings.
The Table Cleanup Tool may not work in all cases, please ensure you check the code and make sure the table is built properly.

Quick Guide (without using the Table Cleanup Tool)

  1. Wrap the table in a <div class="table-responsive"> element.
  2. Apply the table table-bordered classes to the <table> element.
  3. Put the table title in a <caption class="text-left fnt-nrml"> element and follow the HTML structure in the example below
  4. Make sure your table has the proper basic structure.
  5. Add the bg-dark text-white classes on the <tr> elements in the <thead>.
  6. Add the text-right class to the <tr> elements inside the <tbody>. If the row contains a lot of text or a mix of text and numerical data, do not apply the text-right class.
  7. All column headings must be a <th> element
  8. All cells in the far left column (row headings) should be a <th> element
  9. If the row heading spans the full width of the table it should get the active class. We call these Section Headings.
  10. Any left column <th> that is a sub heading (indented) or a child of a , should get the fnt-nrml class to remove the default bolding.
  11. If the table has notes, footnotes or sources, make sure to put that content in the <tfoot> element and you use the proper HTML structure shown below.

Quick Guide

  1. Paste the snippet in your page
  2. Copy everything inside the table tags of the table you want to convert
  3. Paste it inside the table tags of the snippet
  4. Copy the Table # and Table Name from the old caption and paste them in the snippets caption
  5. Delete the old caption.
  6. To filtering issues in french:
    • Set the French thousands seperator by using &ThinSpace; instead of &nbsp;. For example: 1&ThinSpace;000&ThinSpace;546. Make sure there are not spaces between the html tags in the cells in this column.
    • Set the French thousands seperator by using &ThinSpace; instead of &nbsp;. For example: 1&ThinSpace;000&ThinSpace;546. Make sure there are not spaces between the html tags in the cells in this column.
  7. Set the French decimal by setting "decimal": ","
  8. Test to make sure Filtering and Sorting is working properlly.

<!--This is the french Data Tables snippet-->
<div class="table-responsive">
    <caption class="text-left fnt-nrml">
        Table #<br>
        <strong>TABLE NAME</strong> <br>
    </caption>
    <table class="table table-bordered wb-tables" style="border:none" data-wb-tables='
                {"language": {
                    "thousands": "&ThinSpace",
                    "decimal": ","
                    }
                }
            '>
            <!--Paste everything inside the table tags here-->
    </table>
</div>
