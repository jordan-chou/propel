Information

  1. Open a Word document.Choose a .doc or .docx file, or drop it into the editor.
  2. Review and edit.Use Live view for visual editing and Code view for direct HTML changes. Both views stay synchronized.
  3. Enhance the markup.Use the tools to add IDs, generate footnotes, validate non-breaking spaces, and clean tables.
  4. Check the result.Open Activity and review the Report and Review tabs for structural issues.
  5. Copy the HTML.When the document is ready, select Copy HTML at the bottom of the Tools panel.
  • Run cleanup tools after the document is imported so they work from the converted HTML.
  • Use undo and redo in whichever editor or table editor is currently active.
  • Check both Live and Code views after structural changes such as footnotes or table cleanup.
  • Use the language switch before generating language-specific publishing text.
  • Resolve items in the Review panel before copying the final HTML.
