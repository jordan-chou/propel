Information

  1. Open a Word document.Choose a .doc or .docx file, or drop it into the editor.
  2. Review and edit.Use Live view for visual editing and Code view for direct HTML changes. Both views stay synchronized.
  3. Enhance the markup.Use the tools to add IDs, generate footnotes, validate non-breaking spaces, and clean tables.
  4. Insert reusable components.Place the cursor in Live or Code view, choose Insert component, preview a library entry, then select Insert. The snippet is added at the captured cursor position with editable placeholder text.
  5. Check the result.Open Activity and review the Report and Review tabs for structural issues.
  6. Copy the HTML.When the document is ready, select Copy HTML at the bottom of the Tools panel.
  • Run cleanup tools after the document is imported so they work from the converted HTML.
  • Use undo and redo in whichever editor or table editor is currently active.
  • Check both Live and Code views after structural changes such as footnotes or table cleanup.
  • Component insertion uses the captured Live or Code cursor position and does not replace highlighted content. Replace the inserted placeholder text in either editor.
  • To populate a component from a source table, use the table's Live hover action or Convert current table to component in the table editor. Chart text versions receive editable placeholders rather than copied table content.
  • Choose Create new component to add a name, optional description, and HTML template containing exactly one {{content}} slot. Library changes, including created or deleted components and imports, persist for the same browser and app origin until that site's data is cleared.
  • Use the component library ellipsis menu to export the active versioned JSON library or import another one. Importing replaces the active library, so export it first if you want a backup.
  • Use the language switch before generating language-specific publishing text.
  • Resolve items in the Review panel before copying the final HTML.
